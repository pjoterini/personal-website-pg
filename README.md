# Personal Portfolio

[Portfolio preview](https://piotrgorski.com)

## Description

My personal portfolio made with HTML, SCSS and vanilla JS.

Bundled with webpack.

## Setup

1. Use Node.js 22 LTS or newer. The current webpack dev tooling requires Node 22.15.0+.
2. Install dependencies:

   ```bash
   npm install
   ```

## Development

Run the app in development mode:

```bash
npm run dev
```

This starts the webpack dev server with hot reloading and opens the browser automatically.

## Production build

To create a production build:

```bash
npm run build
```

## Other scripts

- `npm start` — runs the production webpack server
- `npm run dev` — runs the local development server
- `npm run build` — creates a production bundle
